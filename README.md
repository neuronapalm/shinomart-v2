# Shinomart v2 — локальная демонстрационная версия

Одностраничная демонстрационная версия по предоставленным десктопному и мобильному макетам. Сайт не является официальным сайтом организации и не утверждён её владельцем.

## Запуск

Нужен Node.js 20 или новее. Из этой папки:

```powershell
node serve.mjs
```

Откройте `http://127.0.0.1:4174/`. Зависимости и сборка не нужны. Для повторной браузерной проверки при установленном Google Chrome:

```powershell
node qa/check.mjs
```

Скрипт сохраняет снимки 360, 390, 430, 768, 1440 и 1920 px в `qa/screenshots/` и результат в `qa/browser-results.json`. Он прокручивает страницу для загрузки внешних блоков, затем проверяет изображения, горизонтальное переполнение, ошибки JS, меню, внутренние ссылки, фокус и режим уменьшенного движения.

## Структура

- `index.html`, `styles.css`, `script.js` — страница и взаимодействия.
- `serve.mjs` — локальный HTTP-сервер без пакетов.
- `shinomart_codex_package/assets/` — используемые концептуальные логотип и hero-изображение. Остальные исходники пакета сохранены в локальной рабочей копии и не входят в публичный репозиторий.
- `assets/generated/` — восемь оптимизированных концептуальных WebP для карточек задач и услуг.
- `qa/check.mjs` — воспроизводимая браузерная проверка; снимки и отчёты создаются локально и не входят в публичный репозиторий.

## Основа контента

Сведения взяты из исследовательских файлов локального проекта `shinomart-site`, прежде всего из `research/evidence-register.md` и `research/semantic-audit/pain-solution-matrix.md`. Эти рабочие файлы не входят в публичный репозиторий. Отзывы выводятся официальным виджетом Яндекс Карт вместе с прямой ссылкой. Отдельная строка 5,0 / 62 оценки / 45 отзывов — датированный снимок от 12.10.2026; актуальные данные показывает виджет. Тексты и авторы отзывов в код страницы не копировались. Контактная карта также встраивается из Яндекса по ID организации `226313350604`.

Шрифты Montserrat и Inter загружаются через Google Fonts. Оба семейства в реестре Google Fonts имеют лицензию OFL и кириллический набор: [Montserrat](https://github.com/google/fonts/blob/main/ofl/montserrat/METADATA.pb), [Inter](https://github.com/google/fonts/blob/main/ofl/inter/METADATA.pb). При отсутствии сети используются локальные системные шрифты. На браузерной проверке оба семейства загрузились.

Сайт не содержит формы заявки, онлайн-записи, цен, режима работы и неподтверждённых гарантий. Основные действия ведут на подтверждённый `tel:` и точную карточку Яндекс Карт.
